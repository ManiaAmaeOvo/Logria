# 测试与反馈指南

朋友共享测试使用 1.3.0 build 10，包含历史训练补录／修改、默认休息及凌晨 04:00 分日，并合并此前本地版本的文档／更新日志。旧 1.2.0 Release 保留。
官方签名 APK 应覆盖安装，不要先卸载或清除存储；新安装无私人日志。目前没有可恢复备份／导入功能。

本地 build 8 的完整 80 项测试、静态检查及格式检查通过，另包含系统语言解析、更新日志页面内语言变化和中文文档链接检查。
本地 build 9 的 96 项自动测试及静态检查通过，新增旧日期迁移、04:00 边界、固定编辑日期、历史替换／回滚、重复日保护、过期版本拦截、旧轮不重开、当前轮完成／撤销／恢复、起始日覆盖及双语补录表单测试。
模拟器原位升级验证了旧饮食及身体数据保留、签名一致、build 编号递增、无联网权限、双语手册和快捷添加布局。
后续本地改动的具体验证记录见英文发布流程文档；这些检查不意味着没有尚未发现的设备差异。

## 建议测试清单

- 凌晨 03:59 默认记录昨天，04:00 默认记录今天；检查前台跨界、恢复前台及饮食／身体／有氧／PR的一致性。
- 日历所选日期及已打开编辑器日期不得自动偏移；旧凌晨条目保留旧日期。
- 补录训练，改成休息／跳过，再改回训练；后续训练、饮食、身体及独立手动 PR 不变。
- 同轮同日不可重复占用；取消不修改记录；当前轮进度重算，旧轮不重开；历史编辑草稿可以继续。
- 空白日期显示休息但不写入操作、不消耗计划休息日。

- 选择并编辑计划，从 Push 2 开始记录。
- 输入部分组，退出后继续，完成并编辑已保存训练。
- 手动改下面一组，再改第一组，检查受保护字段。
- 记录休息后尝试再次操作，撤销并恢复。
- 创建动作变式，确认基础预设和历史不变。
- 追踪一个 PR，添加／删除手动值，记录独立有氧。
- 重启中断的循环，沿用上一轮同计划日的记录。
- 保存每日复盘，复制今日与日历历史日期。
- 先记纯文本餐，再补营养，设置并恢复每日手动总量。
- 快捷添加内置和自建食品，用小数份量；测试取消、无结果搜索、过去日期及数值精度。
- 创建按瓶／份的预设，修改 kJ、kcal 和 P/C/F，验证手动热量不会被覆盖，直到重新开启估算。
- 钠设置上限，另一营养设置下限，部分值留空，确认不完整提示而不是假零。
- 不同日期只更新部分身体指标，确认历史曲线不伪造缺失值。
- 离线打开设置中的手册和更新日志，展开历史版本；切换应用中英文或跟随系统，确认更新日志自动匹配语言。
- 使用大系统字号和键盘重复测试，重启应用验证记录和语言保留。
