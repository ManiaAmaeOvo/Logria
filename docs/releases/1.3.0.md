# Logria 1.3.0 (Android build 10)

## 简体中文

- 训练页或日历可补录／修改指定日期，重新选择训练、休息或跳过。
- 选择匹配的计划／轮次／计划日；同轮计划日不可重复占用，后续训练不被挪动。
- 当前轮进度重新计算，已关闭轮次保持关闭；补录支持草稿及确认保存。
- 未记录日期默认显示休息，不写入操作、不消耗计划休息日。
- 今日、训练、饮食和身体统一在设备本地凌晨 04:00 分日；手选日期、编辑中日期和旧记录日期保持不变。
- 合并中文文档、双语离线手册和自动跟随应用语言的内嵌更新日志。
- 增量数据库迁移保留已有数据，96 项自动测试及静态检查通过。

安装 `logria-v1.3.0-android.apk`，直接覆盖安装，不要卸载或清除应用数据。
将训练改成休息或跳过会移除该日力量组及训练 PR 贡献，保存前有确认。
新补录的历史条目以 12:00 占位，并非实际训练时间。旧 1.2.0 Release 保持不变。
目前仍无可恢复的文件备份／导入功能，应用完全离线，不申请联网权限。
APK 沿用已有本地开发签名，保证现有官方 APK 可覆盖升级；并非 Google Play 发布包。

## English

- Backfill or correct a selected training date as training, rest or skip.
- Explicit plan/cycle/day binding prevents duplicate slots and preserves later workouts.
- Live progress recalculates; closed rounds stay closed. Drafts and save confirmation are supported.
- Unrecorded dates display implicit rest without consuming planned rest slots.
- Default journal dates use the device-local 04:00 cutoff across modules. Explicit selections,
  open-editor dates and legacy dates are preserved.
- Includes previously local-only Chinese docs, bilingual offline manuals and localized changelog.
- Additive migration preserves existing data; all 96 automated tests and static analysis pass.

Install `logria-v1.3.0-android.apk` over the existing installation; do not uninstall or clear storage.
Replacing training with rest/skip removes that date's strength sets and workout PR contribution
after confirmation. Newly backfilled past entries use noon as a placeholder, not the actual time.
No restorable file backup/import is available yet. The app remains offline without Internet permission.
The APK retains the existing local development signing identity for upgrade compatibility;
this is not a Google Play distribution. The v1.2.0 release/assets/tag remain unchanged.
