# Logria 1.4.1 (Android build 14)

## 简体中文

- 多食材餐在今日营养表格及复制的 Markdown 中逐食材分行显示用量、P/C/F、kcal 和可选矿物质，不再挤在同一格。
- 餐合计保留保存值，日总量保留逐餐合计／手动总量，不重复累加明细；未知值和零值保持区分。长按截断名称可查看完整内容。
- 合并本地 build 13：今日训练／休息／跳过后明确显示「下次计划日」，隐藏不可用操作，顶部三个入口等宽、等间距。
- 饮食页新增随目标／上限调整的熟米饭、全蛋／生鸡胸营养换算，采用已有 USDA 参考值，仅展示、不保存，不代替配餐建议，也不综合其他营养或热量限制。
- 更新双语内嵌手册、日志及测试说明。135 项测试通过。

下载 `logria-v1.4.1-android.apk` 直接覆盖安装，包括本地 build 13；不要卸载或清除数据。
沿用签名、数据库 schema 7、备份格式 1，不增加数据库字段或权限；旧 Release／标签／安装包保留。
完整备份为未加密敏感文件，请妥善保管。沿用开发签名以兼容覆盖安装，非 Google Play 发布包。

## English

- Composed meals now use one row per ingredient in Today and copied Markdown,
  with independent quantities, P/C/F, kcal and optional minerals.
- Recorded meal subtotals and selected meal/manual daily totals remain unchanged;
  detail rows are not additional intake. Unknown and zero values stay distinct.
  Long-press truncated labels for the full text.
- Includes local build 13: explicit next-planned-day status after today's action,
  hidden inactive controls and equal-width, consistently spaced Fitness shortcuts.
- Display-only food equivalents adapt to carbohydrate/protein targets or limits,
  using existing USDA cooked-rice, whole-egg and raw-chicken references. They are
  not saved or a combined meal recommendation and do not include other limits.
- Updated bilingual bundled guides/changelog and testing docs; 135 tests pass.

Install `logria-v1.4.1-android.apk` over the existing app, including local build 13.
Do not uninstall or clear storage. Signing identity, database schema 7 and backup
format 1 are unchanged; no new database fields or permissions. Older releases,
tags and assets remain intact. Full backups are unencrypted sensitive files.
The existing development signature is retained for upgrades, not Google Play distribution.
