# Logria 1.4.3 (Android build 18)

## 简体中文

- 按住动作手柄时，卡片折叠为仅显示动作名称。松手后恢复组数据和编辑控件。
- 「临时保存」保留已输入内容及排序，保存后可直接继续编辑。
- 新训练从首次修改组数据开始计时，到点击完成训练为止。退出并恢复草稿的间隔计入用时，训练详情和每日汇总可查看用时。
- 今日、日历和复制的训练日志按活动时间排列有氧与力量。添加或补录有氧时可指定活动时间。

下载 `logria-v1.4.3-android.apk` 覆盖安装，适用于本地 build 17 和此前正式版本。APK 校验值见 `SHA256SUMS`。发布包通过 153 项自动测试。

## English

- Holding an exercise handle collapses the cards to names for drag sorting.
  Set fields and controls return after dropping.
- Save Draft preserves the current inputs and order and keeps the editor open.
- New workouts time the interval from the first set edit to Finish, including
  time spent away from a saved draft. Workout details and daily logs show the duration.
- Today, Calendar, and copied fitness logs sort cardio and strength by activity time.
  You can set the activity time when adding or editing a cardio entry.

Install `logria-v1.4.3-android.apk` over an existing installation, including local
build 17. The APK checksum is in `SHA256SUMS`. The release passed 153 automated tests.
