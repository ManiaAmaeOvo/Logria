# Logria 1.2.0 · Android build 7

An offline testing release for fitness, nutrition and body journaling.

## Highlights

- Daily review notes, non-destructive cycle restart and previous-workout templates.
- One-shot first-set weight/reps filling, with protection for manually edited sets.
- Exercise variant notes saved as independent presets and separate PR series.
- 12 offline reference foods plus custom food/product/meal presets with explicit
  gram, mL, portion, bottle, scoop or bag bases.
- Quick-add presets directly from the daily Food log, with search/amount preview.
- Linked kcal/kJ editing; optional sodium, potassium, calcium, iron and fiber
  recording, daily overrides and goal/minimum/limit targets.
- Numeric nutrition displays limited to four decimal places; unknown is not zero.
- English and Chinese user manuals available offline in Settings and on GitHub.

## Install / 安装

Download `logria-v1.2.0-android.apk`. Android 7.0 or later is required. Install
over the existing official APK; the signing identity is unchanged. Do not
uninstall or clear app storage. Additive schema 5 migrations preserve records.

下载 APK 后直接覆盖安装，不要先卸载或清除数据。中英文说明均在设置 → 使用说明中，可离线阅读。

## Known limits / 当前限制

No restorable backup, JSON file import/export, cloud sync, automatic recipe
builder or built-in LLM calls. Preserve app storage. Clipboard logs cannot restore
the database. Please report reproducible issues without exposing private data.

目前无可恢复的备份或 JSON 文件导入导出；复制日志不能用于恢复数据库。反馈请附版本、系统、语言和复现步骤，并隐藏个人数据。
