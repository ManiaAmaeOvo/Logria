# Logria 1.4.0 (Android build 12)

## 简体中文

- 设置新增完整 JSON 备份／恢复，以及按日期范围导出分析日志（可排除身体／睡眠）。
- 身体页新增睡眠时间、时长和备注，纳入今日、日历及相应导出。
- 单组独立感受备注，不创建动作变式、不拆分 PR；RIR 支持约数和区间等自由文本。
- 饮食「+」可将多个预设食材合为一餐，按用量计算，支持备注及手动调整总量。
- 常用数字输入支持四则运算和括号，次数／组数仍须为整数。
- 训练快捷入口同排；修正完成后训练参考标题及文本重量选择框尺寸。
- 今日营养使用紧凑表格，复制输出 Markdown 表格。
- SQLite schema 7 增量迁移保留旧数值 RIR、记录及草稿；119 项测试通过。

下载 `logria-v1.4.0-android.apk` 直接覆盖安装，不要先卸载或清除存储。
Build 12 高于本地测试版 build 11，旧 1.3.0 Release 保持不变。

备份**未加密**，请妥善保管。恢复会替换当前全部数据，建议先另存完整备份；
日期分析导出和剪贴板日志不能恢复数据库。当前备份版本为 1、数据库 schema 为 7，
只接受兼容版本的完整备份，单文件上限 32 MiB。
旧版孤立训练动作／组的完整原始快照保存在 `backup.orphanedWorkoutRows` 隔离归档中，
恢复前明确提示，不静默删除，也不计入训练或 PR。其他不支持的外键异常会阻止备份创建。
文件选择器可提供第三方云端位置；选择本地位置即可离线使用。
仍沿用既有开发签名以保持覆盖升级兼容，无联网或广泛存储权限；非 Google Play 发布包。

## English

- Full JSON backup/restore and inclusive date-range analysis exports, with optional body/sleep.
- Sleep intervals, duration and notes in Body, Today, Calendar and exports.
- Independent per-set feeling notes and free-text RIR; neither creates an exercise variant.
- Multi-ingredient meals with quantity-scaled preset snapshots, notes and editable totals.
- Arithmetic and parentheses in numeric inputs, retaining integer/range validation.
- One-row Fitness shortcuts, clearer pending-day references and normalized text-load selectors.
- Compact nutrient tables in Today and escaped Markdown clipboard tables.
- Additive schema 7 preserves legacy numeric RIR, existing records and drafts; 119 tests pass.

Install `logria-v1.4.0-android.apk` over the existing app, including local build 11.
Do not uninstall or clear storage. Previous releases/assets/tags remain unchanged.

Backups are **unencrypted**. Restoration replaces all current data: save a separate full backup
first. Analysis exports and clipboard logs are not restorable. Backup format 1 currently requires
compatible database schema 7; files are limited to 32 MiB. Legacy orphan workout snapshots are
preserved in the disclosed inert `backup.orphanedWorkoutRows` archive, not dropped or counted
as workouts/PRs. Other unsupported reference errors block backup creation. Choose a local
document-provider location for offline use; third-party providers may offer cloud storage.
The APK retains the existing development signing identity for upgrade compatibility, with no
Internet/broad storage permissions. This is not a Google Play distribution.
