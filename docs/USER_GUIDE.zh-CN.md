# Logria 1.3 使用说明

[English](USER_GUIDE.md)

Logria 是完全离线的 Android 训练、饮食和身体数据记录工具。数据保存在当前设备，不需要账号，不进行云端同步。
设置 → 使用说明中可离线阅读本手册，并独立切换简体中文和 English。

## 安装与开始使用

从 GitHub Releases 下载官方 APK。根据 Android 提示允许浏览器或文件管理器安装应用。最低支持 Android 7.0（API 24）。
升级时直接覆盖安装，不要先卸载或清除应用数据；升级包必须使用相同签名。不同手机不会自动共享数据。

设置中可选择简体中文、English 或跟随系统。日期使用设备本地时间。
底部五个标签分别是今日、训练、饮食、身体、日历。记录日统一从凌晨 04:00 到次日 04:00：凌晨 02:00 默认记录到昨天，适用于今日、力量／有氧／PR、饮食及身体。日历手选日期不会再次偏移；旧记录日期不变。训练编辑器显示并固定记录日期，跨过分日时间保存仍属于原日期，要记录新日期请重新进入。

## 补录和修改日期

训练页点击「补录／修改训练日期」，或在日历选择日期后使用同一入口。选择训练、休息或跳过，再选择匹配的计划／轮次及计划日。同一轮已在其他日期记录的计划日不可重复占用。休息可选择计划休息日或额外休息；跳过须选择训练日。训练进入可保存草稿的编辑器，未填完可以退出后继续；取消不改变已保存记录，确认保存才替换指定日期。

只修改选中日期，后续训练不会改名或重新排列；当前轮次按已记录的计划日重新计算待训练内容。修改已关闭轮次不会重开或删除后续轮次；补齐当前轮最后一个未记录计划日会开启下一轮。当前轮也可用于开始记录前的日期补录，请核对轮次。
将训练改为休息或跳过会移除该日力量组及其训练 PR 贡献，不影响独立手动 PR、有氧、饮食或身体数据。已有发生时间保留；新补录的历史条目以中午 12:00 占位，并非实际训练时间。

没有力量操作记录的日期显示「默认休息」，仅有有氧时也一样。默认休息不写入记录、不占用计划休息日、不推进训练。主动记录休息仍按正常计划规则处理；不允许记录未来日期。

## 训练计划与起始日

进入训练页，选择三分化 PPL、PPL × 2 或胸背肩腿四分化预设。计划菜单可以编辑计划或切换预设。
切换预设会开始新计划，之前的训练历史不会删除。可调整每日主题、顺序、休息日和动作目标。

一轮尚未记录任何训练、休息或跳过操作时，可以点击“选择起始日”，例如从 Push 2 开始。
起始日前的日程标记为未记录，不会伪造训练或跳过记录；下一轮仍从第一个日程开始。
如已有草稿，先完成或丢弃草稿，再调整起始日。一旦本轮已记录操作，就不能直接更改起点。

## 记录训练与草稿

点击待训练的日程，选择已有动作或手动输入动作名称。新动作可保存为预设，也可仅用于本次训练。
每组可以填写重量、次数和 RIR。公斤数直接输入 40；40kg 会被当作文本标签，而不是自动解析为公斤。
自重、弹力带等可用文本重量，并选择数值映射为 null（默认，未知，不参与重量 PR）或 0（无可测外部负重）。原文本会保留。

输入后自动保存本地草稿；使用页面返回、系统返回或切到后台时会尽量完成保存。未填完或暂时无效的输入可以继续编辑。
草稿不会推进训练轮次，也不会覆盖已完成的记录。点击完成并保存，或编辑已完成训练时点击保存修改，才提交正式记录。
空白组会忽略，未填的重量、次数或 RIR 保持未知。计划目标不会自动当作实际完成值。
不要依赖输入后立即强制关闭进程来保存最后一个字符。“丢弃草稿”需要确认，不会删除此前已保存的训练。

同一动作有多组时，首次聚焦编辑第一组的重量或次数，会把值同步到下方尚未手动编辑的对应字段。
离开该输入框后，再修改第一组不会重复同步。下方某组手动修改后，该字段受到保护，不影响上方组；重量与次数分别处理，RIR 不同步。
同步状态随草稿保存。首次编辑之后新加的组仍为空；编辑已经完成的训练不会自动覆盖其他已保存组。

## 动作变式、PR 与有氧

在动作卡片选择“变式备注／独立预设”，例如高位下拉备注“正手·宽距”。系统创建“高位下拉 [正手·宽距]”独立预设，不污染原动作或历史记录。
变式保留当前输入，并随草稿恢复。在计划的动作菜单中也可创建变式，只替换那个计划条目。
清空备注可回到基础动作，不会删除已创建的变式预设。不同名称或变式可以分别追踪 PR。

从训练页进入动作 PR，手动选择需要追踪的动作。曲线表示每日记录的最大数值重量，不是估算的 1RM。
文本映射为 null 的重量不参与曲线，映射为 0 的重量计为 0。可补录日期、重量和可选次数的手动 PR，并删除手动记录。
取消追踪只隐藏曲线，不删除训练；修改训练会更新其曲线贡献。中英文不同动作名称也视为不同序列。

有氧记录独立于力量训练循环，休息日或未选计划时也可记录。选择常见项目或自定义名称，填写日期、分钟数，以及可选公里数和备注。
点击记录可编辑，删除前会确认。有氧会出现在今日、日历和复制日志中，但不会随上次力量训练模板一起复制。

## 休息、跳过、撤销与重新开始

提前休息会消耗下一项预设休息日，同时保留待训练的日程；例如 Push 1 后休息，之后仍接 Pull 1。
本轮没有预设休息日可用时，额外休息不推进训练位置。跳过某训练日则前进到下一日程。

一天只允许一项力量训练、休息或跳过操作，避免重复消耗休息日。完成的训练会直接展示，可继续查看或编辑。
撤销会移除最近操作并恢复训练位置。“恢复今日操作”可恢复刚撤销的训练、休息或跳过，包括原组数和轮次。
同一天重启应用仍可恢复，但新的操作、计划或目标编辑、起始日修改、跨日等会让旧的恢复失效。只保留最近一个撤销操作；有氧独立处理。

训练页右上菜单的“重新开始训练循环”会归档中断的循环，并用相同计划开始新一轮。
训练历史、PR、饮食和身体数据不会删除，但未完成的计划日草稿会丢弃，撤销恢复也会失效。
若今日已有操作，先撤销，再重新开始；新循环可再次选择起始日。此功能不是清空所有数据，确认后不能一键恢复旧的循环进度。

## 沿用上次训练

后续轮次遇到相同计划日，可点击“使用上次记录作为模板”，在训练页的上一轮参考卡片或编辑器中使用。
会复制动作、组数、重量及文本映射、次数和 RIR，第一组的首次同步重新可用。
如有当前草稿，覆盖前需要确认。复制仅产生本次草稿，不完成训练，也不改历史；保存前请核对各组值。

## 饮食记录与快捷添加

在饮食页选择日期。“添加饮食记录”可仅记录吃了什么，之后再补 P/C/F；宏量营养单位是克。
输入 P/C/F 默认按 4P + 4C + 9F 粗略计算 kcal。手动修改 kcal 或 kJ 会关闭自动估算，同时换算另一项。
后续修改 P/C/F 不会覆盖手动热量；重新打开自动估算才会再次计算。1 kcal = 4.184 kJ。

在“饮食记录”卡片点击“从预设快捷添加”，搜索食物或自建方案，选择后输入摄入量、检查预览并保存，无需先进入食材管理页。
系统按份量计算已知 P/C/F、热量及附加营养，直接添加到选中的日期。取消选择或份量对话框不会产生记录。
每次添加是独立条目，一餐可分别添加多个食材。点击已记录的条目可直接修改文本和营养，不改变原预设；删除前需要确认。

每天的营养摄入默认汇总已知的逐餐数值。留空表示未知，不等于 0；漏记营养时汇总可能不完整。
可以手动编辑“每日营养摄入”，例如把复制日志发送给自己选择的 LLM 后填入估算总量。
手动总量会覆盖逐餐汇总，之后增加食物不会自动改动此总量。选择“恢复逐餐汇总”才回到自动统计。
P/C/F/kcal 均可设置目标或上限；目标显示还需摄入多少，上限显示剩余额度和超额情况。留空可关闭该项。

## 食材与常用饮食方案

“食材与常用饮食方案”管理可复用的预设，也可以在那里记录摄入。内置 12 种常见食材参考来自 USDA，完全离线。
内置预设只读，需要调整时复制成新预设。生重、熟重等参考不能互换；品牌成品应优先使用其配料表。

点击加号可创建蛋白粉、酸奶、牛奶或自制晚餐等预设。先设定参考量和单位，再填该参考量对应的营养，例如每 30 克蛋白粉或每瓶酸奶。
支持克、毫升、份、瓶、勺、袋，以及小数份量；克重可标记生重或熟重。
整餐预设保存你填写的合计营养，目前没有自动组合食材的配方计算器。

首次输入 P/C/F 会估算热量。根据标签手动修改 kcal 或 kJ 后，另一项同步换算，宏量营养再修改不会覆盖标签热量。
自建预设可编辑或删除，但已记录的饮食保存独立快照，不受之后修改影响。
自动计算值和数值汇总最多显示 4 位小数，并去掉末尾 0；数据库计算保留原精度。编辑并保存时使用输入框当前数字，文本备注和重量标签不做四舍五入。

## 钠等附加营养

在饮食条目、预设、每日摄入或目标编辑中展开“矿物质与膳食纤维（可选）”。支持钠、钾、钙、铁和膳食纤维。
矿物质单位是 mg，膳食纤维单位是 g。每项可设目标、下限或上限，留空则关闭；不会自动替你指定摄入标准。
未知值不是 0，汇总只累计已知值，缺失时标记不完整，不声称准确的剩余额度。
每日手动总量同样覆盖这些营养，恢复逐餐汇总后重新累计。已记录的附加营养会出现在复制日志中。

## 身体数据与曲线

选择日期，点击某个指标快捷记录，或用加号一次输入多个指标。不必每次填写全部项目。
支持体重、身高、体脂率、腰围、臂围、胸围、臀围和大腿围。留空保留该日期已有值；需要移除时使用删除。
趋势与历史可选择指标、近 30 天、近 90 天或全部。没有测量的日期不会补造数据；点击历史值可跳到对应日期。

## 今日复盘、日历与复制

今日页直接展示当天训练、逐餐饮食、营养总量及身体测量。“今日复盘备注”用于记录感受和复盘，输入后点击保存。
保存空备注会删除该日复盘，不影响其他数据。复盘会出现在历史日历和整日复制日志中，不附加到单独板块复制。

顶部按钮一键复制今日全部记录，每个板块也可单独复制；箭头进入对应模块。复制只进入系统剪贴板，不自动发送给他人或 LLM。
日历用图标标记有数据的日期，用颜色标记训练轮次。点击日期后向下查看日志，轮次选择可定位起点；变暗的过去日期仍可选择。
日历的复制针对当前所选日期，不一定是今天。点击今日回到本月当天。复制时重新读取数据库，未知值显示为破折号。

## 数据安全与测试反馈

设置中有版本号、开发人员、GitHub 项目和个人主页、隐私简介及开源许可。
设置 → 更新日志于本地 build 8 引入，并于 1.3.0 公开发布，离线展示版本记录并自动跟随应用语言（包括跟随系统），不像手册可以独立切换。
此入口已包含于公开的 1.3.0 build 10 APK；旧 1.2.0 build 7 尚无此入口。
1.3 仍没有可恢复的备份或 JSON 文件导入导出。不要卸载或清除数据；剪贴板日志不能导入来恢复数据库。

份量计算异常时，先检查参考量和单位，避免把每 100 克的标签数值当成每瓶。营养总量没随饮食变化时，检查是否启用了每日手动覆盖。
训练按钮锁定时，查看今日已完成、休息或跳过的操作；可以编辑训练或先撤销。草稿不等于完成。
记录仅作个人追踪，参考食物数值和 PR 曲线不是医疗建议。

反馈问题可到 GitHub 项目的 Issues，附应用版本、Android 版本、语言、复现步骤、预期与实际结果及已隐藏隐私的截图。
不要无意间公开自己的饮食、身体数据或数据库。后续版本根据真实使用反馈继续调整。
