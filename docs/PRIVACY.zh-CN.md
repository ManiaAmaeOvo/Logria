# 隐私与本地数据

[English](PRIVACY.md) · [中文首页](../README.zh-CN.md)

Logria 的记录保存在当前 Android 设备的 SQLite 中。无账号、云同步、广告、分析追踪或内置 LLM 请求。
Release 不声明 Android INTERNET 权限；Flutter debug／profile 包为开发工具使用联网权限。

训练草稿及未完成的原始输入按日期和训练／计划日保存在本地，完成保存时移除对应草稿。
有氧、手动 PR、追踪偏好、每日复盘、食物预设、份量和附加营养均为本地数据。整日复制包含已保存复盘。
USDA 参考数据内置，不在运行时获取；修改或删除食物预设不改变已记录快照。动作变式创建独立本地预设，不需要账号或联网。
重新开始循环保留历史，但经确认丢弃未完成计划日草稿并清除撤销恢复。
撤销保存一个本地快照，供同日恢复；失效快照可能保留至替换或被新力量操作清除，不会为撤销／恢复传输数据。

应用要求禁用 Android 自动备份，当前没有备份恢复界面。卸载或清除存储可能移除记录。
剪贴板复制只是文本分享，不是可恢复备份。复制后是否粘贴到其他应用或发送给 LLM 由用户决定，系统和其他应用适用各自的剪贴板规则。

中英文使用说明和更新日志随 APK 打包、离线读取，不从 GitHub 下载。
只有主动点击 GitHub 链接才打开外部浏览器，后续流量属于浏览器及 GitHub，不属于日志存储。

公开问题反馈请用虚构数据。Android 应用沙箱保护应用存储，但本版本没有额外的数据库加密。
